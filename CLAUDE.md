# Site de Jean-Michel Ribeyrolles — refonte

Sculpteur sur bois brûlé et musicien, ART'elier Samonteil (Lot).
Site vitrine, futur site statique Astro. Contexte : docs/audit/ et docs/design/DESIGN.md.

## Identité à respecter (non négociable)
- Fond sombre : principal #1B1A19 (noir chaud), surfaces #2D2D2D, header #0A0A0A
- Accent unique #DD9933 : liens, boutons, filets. Jamais en aplat derrière une œuvre.
- Un seul blanc cassé pour le texte, gris chaud pour le texte secondaire
- Typos : Roboto pour tout le texte (paragraphes, titres, menu, footer) ;
  Swanky and Moo Moo pour le logo du header et l'accroche uniquement.
  Roboto est un choix de l'artiste : ne pas la remplacer.
- Logo manuscrit orange du header : texte « Jean-Michel RIBEYROLLES » en Swanky and Moo Moo, `#DD9933`, 40 px, inchangé (voir DESIGN.md, Composants)
- Signature JmiR : image, inchangée
- Angles droits, pas d'ombres portées ni de dégradés décoratifs

## Principes
- Les sculptures sont le contenu principal : grandes, jamais recadrées, espace autour
- Les œuvres n'ont pas de titre : la référence reste discrète, comme un cartel de musée
- Les textes poétiques des collections sont des vers : conserver les retours
  à la ligne d'origine, en romain (pas d'italique), sans recomposer les lignes.
- Textes alternatifs générés : collection + matériaux + dimensions
- Mobile aussi soigné que desktop
